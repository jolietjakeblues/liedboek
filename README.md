# Liedboek

Persoonlijk liedboek met Google Drive als bron en GitHub Pages als publicatieplek.

## Uitgangspunten

- Google Drive is de bron.
- Liedteksten worden niet naar GitHub gecommit.
- De GitHub Action haalt de teksten tijdens de build uit Drive.
- Alleen het gebouwde GitHub Pages-resultaat wordt gepubliceerd.
- Er staat bewust geen open-sourcelicentie op de liedteksten.
- De site vraagt zoekmachines standaard om de site niet te indexeren.
- Alleen documenten uit de gekozen publicatiemap in Drive worden gepubliceerd.

Zie `SETUP.md` voor installatie en `PUBLICEREN.md` voor dagelijks gebruik.
