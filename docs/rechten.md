# Auteursrecht en gebruik

Alle liedteksten en composities op deze website zijn auteursrechtelijk beschermd, tenzij bij een werk anders staat vermeld.

Copyright © Joop Vanderheiden. Alle rechten voorbehouden.

Publicatie op deze website geeft geen toestemming voor herpublicatie, verspreiding, bewerking, vertaling, opname, commerciële exploitatie of ander hergebruik waarvoor toestemming nodig is.

Een deel van de werken kan zijn aangemeld bij BumaStemra. Waar dat voor een afzonderlijk lied is vastgelegd, staat dit op de betreffende liedpagina vermeld.

Voor gebruik waarvoor toestemming nodig is, neem contact op met de auteur.

## Technisch

De liedteksten worden tijdens de website-build uit een afgeschermde Google Drive-map gelezen. Ze worden niet als bronbestanden in de GitHub-repository opgeslagen.

De website vraagt zoekmachines standaard om de pagina's niet te indexeren of in een cache te bewaren. Dat is geen kopieerbeveiliging. Openbaar leesbare tekst kan technisch altijd worden gekopieerd.
